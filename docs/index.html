AxisWright

Free & open-source parametric 3D CAD for Android tablets, smartphones, and Chromebooks (GPL-3.0-or-later).

AxisWright combines exact B-rep 3D geometry powered by Open CASCADE Technology with touch, stylus, and mouse controls, plus an optional OpenSCAD-compatible script editor powered by Manifold. The app works 100% offline: no user accounts, no ads, no tracking, and no internet permission.

GitHub Repository Releases (APK) Privacy Policy (DE / EN)

Key Features

  • 2D sketching with 16 geometric constraints, 8 dimension types, transform, and text contours for engraving/embossing
  • 3D parametric modeling: extrude, revolve, counterbore/countersink holes (M3–M10), fillet, chamfer, shell, patterns, mirror, and section view
  • Named parameters and math formulas, plus 3D measurement tools
  • Exact STEP export for CAD exchange and STL/3MF export for 3D printing
